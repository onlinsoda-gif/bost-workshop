BOST WORKSHOP - Prototype (Dari/Pashto/English)

To preview:
1) Unzip this folder.
2) Open index.html in a modern browser (Chrome recommended).

Features in this prototype:
- Language switcher: Dari, Pashto, English
- Workshop banner and small profile logo
- Vehicle registration (stored locally in browser)
- Repair-history entries
- Oil-change reminder date (stored locally)
- Expense tracking and total
- Inspection checklist
- Reminders, warranty log, discounts information
- Dashboard warning-light guide
- Resale history summary
- Repair-estimate request (local demo only)
- Tire-care tips
- Emergency-call button configured to call +93 70 761 0026

Important:
This is a front-end demo only. Records are saved in the same browser/device using local storage.
It does not have an admin/backend database, real push notifications, user accounts, cloud sync,
real workshop appointment processing, or actual estimate submission. Before publishing,
Emergency-call number is configured in index.html as +93707610026. Connect a backend for shared records.
